> **归档时间**：2023 年 6 月

---

## 📖 项目简介
本系统是基于 **Java (Swing / AWT) + MySQL (JDBC)** 开发的桌面版电影院售票与管理系统。  
项目分为**前台客户端**（面向普通观影用户）与**后台管理端**（面向影院管理员），实现了从影片浏览、选座购票、订单生成到后台排片、数据统计的端到端闭环。

---

## 🛠️ 技术栈
* **开发语言**：Java (JDK 8 / 1.8)
* **GUI 框架**：Java Swing, AWT
* **持久层技术**：原生 JDBC
* **数据库**：MySQL (5.7 / 8.0)
* **第三方依赖**：`mysql-connector-java-5.0.8-bin.jar`
* **开发工具**：Eclipse / IntelliJ IDEA

---

## 🌟 核心功能模块

### 1. 前台观影系统 (普通用户)
* **用户认证**：支持用户登录、注册、退出登录。
* **影院首页**：轮播/展示热门影片海报、今日票房排行榜。
* **影片资讯**：影片信息查询、上映排期、剧情简介及详情浏览。
* **选座购票**：可视化座位布局，支持选座、座位锁定及模拟购票结算。
* **个人中心**：个人资料查看与修改、我的购票历史与订单记录查询。

### 2. 后台管理系统 (管理员)
* **管理员鉴权**：专属管理员登录通道。
* **影片信息管理**：新影片录入、修改、下架及详情维护。
* **排片排期管理**：影厅排片规划、场次时间安排、放映厅关联。
* **订单数据管理**：全院出票记录查询、退票与异常订单处理。
* **用户与权限管理**：注册会员信息查看与状态管理。

## 🚀 快速启动指南

### 1. 导入数据库
1. 启动本地 MySQL 服务（推荐 MySQL 5.7 或 8.0）。
2. 创建数据库 `yyspxtdb`（字符集建议 `utf8mb4`）。
3. 导入 [`sql/yyspxtdb.sql`](sql/yyspxtdb.sql)。
4. 如有需要，修改 `src/后台/shujukulianjie/Mysql.java` 中的数据库用户名与密码（默认 `root` / `qwer`）。

### 2. 项目运行
* **前台入口**：运行 `src/前台/yunxing/Test.java`
* **后台入口**：运行 `src/后台/xitongGL/Guanliyuanxitong.java` 或对应的后台登录入口类。

## 💡 成长心得与回顾
这是大学阶段独立完成的一个端到端 Java 桌面应用课设。通过这个项目，我深入掌握了：
1. 面向对象编程（OOP）思想在实际业务中的拆分与封装；
2. Java Swing 容器、布局管理器（BorderLayout, FlowLayout, GridLayout）以及事件监听器机制；
3. 原生 JDBC 的事务思想、PreparedStatement 防 SQL 注入及连接池管理的基础概念；
4. 数据库表关联设计（用户表、电影表、排片场次表、座位状态表、订单表）。

虽然回头看界面风格和代码组织尚显青涩，但它见证了我编程道路上的第一次完整工程落地，也是后续迈向 Web 企业级开发坚实的基石！
