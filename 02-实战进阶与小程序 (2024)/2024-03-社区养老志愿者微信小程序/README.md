# 🧓 基于 Spring Boot 的社区养老志愿者微信小程序 (Community Elder Care)

> **研发与归档时间**：2024 年 03 月  
> **所属阶段**：02-实战进阶与商业小程序交付  
> **架构类型**：前后端分离 (Spring Boot 2.7 + Uni-app Vue 3 + 微信小程序)  
> **作者**：吴琦  

---

## 📖 项目背景与愿景
随着人口老龄化加深，独居老人、高龄老人的日常照护与紧急响应成为社区治理的重要挑战。  
本项目是一套针对**“老有所依、志愿互助”**社区场景打造的数字化闭环平台。系统打通了**社区老人**、**青年志愿者**与**社区管理人员**三方，通过微信小程序的即时性与低门槛优势，实现老人“一键呼叫求助、日常帮扶派单、志愿积分激励”的可持续互助生态。

---

## 🛠️ 技术栈与全栈选型

### 1. 后端架构 (Backend)
* **核心框架**：Spring Boot 2.7.18 (Java 17)
* **数据库持久层**：Spring Boot Starter JDBC / 原生 SQL 优化
* **数据库**：MySQL 8.0 (HikariCP 连接池高效调度)
* **API 风格**：RESTful JSON 交互规范
* **服务端口**：`19000`

### 2. 前端端侧 (Miniprogram)
* **跨端框架**：Uni-app (Vue 3 语法体系)
* **构建工具**：Vite
* **样式处理**：SCSS (`uni.scss` 统一主题变量规范)
* **运行平台**：微信小程序原生运行环境 / H5 预览

---

## 🌟 核心业务矩阵与多端功能

### 1. 👴 社区老人端（极简大字关怀模式）
* **老人专属首页**：清晰大图标导航，常用帮扶一键直达。
* **发布服务需求**：支持陪诊就医、生活代购、卫生清洁、日常陪伴等多类型需求填报。
* **一键紧急求助 (SOS)**：一键上报当前位置与紧急联络人报警，优先触发社区快速响应。
* **我的需求追踪**：待接单、服务中、已完成状态可视化跟踪。
* **服务评价反馈**：帮扶完成后对志愿者服务质量进行星级评价。

### 2. 🤝 志愿者端（爱心接单与互助）
* **志愿需求广场**：按就近距离、服务类型智能推荐可接工单。
* **志愿接单与履约**：查看老人住址与特殊备注，上门服务打卡与完工确认。
* **爱心积分档案**：每一次志愿服务自动累积爱心积分，支持积分荣誉排行与权益兑换。

### 3. 🛡️ 社区管理与数据沉淀
* **老人与志愿者档案认证**：实名审核与特殊病史健康标签管理。
* **工单全局监控**：异常滞留超时工单预警与协调处置。

## 🚀 快速启动指南

### 1. 数据库初始化
1. 启动本地 MySQL 服务；
2. 新建数据库 `community_elder_care`（字符集 `utf8mb4`）；
3. 依次导入 [`sql/schema.sql`](sql/schema.sql) 与 [`sql/seed.sql`](sql/seed.sql)。

### 2. 启动后端 API 服务
```bash
cd src/backend
mvn clean spring-boot:run
# 或在 IDEA 中打开 backend 目录直接运行主类
# 后端服务运行于: http://localhost:19000
```

### 3. 启动微信小程序端
```bash
cd src/miniprogram
npm install
npm run dev:mp-weixin
```
* 构建成功后，打开 **微信开发者工具**；
* 选择「导入项目」，目录指向构建生成的 `dist/dev/mp-weixin`（或在微信开发者工具中直接导入当前 miniprogram 工程）；
* 填写测试 AppID（或选择测试号），即可在模拟器中体验老人呼叫与志愿互助流程。

## 💡 商业交付心得与设计沉淀
1. **适老化交互设计**：考虑到高龄老人视力与认知障碍，在小程序端注重高对比度色块、大字体与简明操作流，避免多层嵌套跳转；
2. **轻量级敏捷落地**：采用 Spring Boot + Uni-app 组合，在保障系统稳定性的同时，实现了移动端跨端发布与极速迭代上线；
3. **真实商业兼职沉淀**：本项目为 2024 年真实承接并完整交付的兼职落地项目，具有完整的需求论证与业务闭环。
