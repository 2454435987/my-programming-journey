# 🐱 宠物管理与社交分享系统 (Pet Social & Adoption Platform)

> **研发与归档时间**：2024 年 10 月  
> **所属阶段**：02-实战进阶与商业小程序交付  
> **架构类型**：前后端分离 (Spring Boot + 原生微信小程序 + 后台运营管理)  
> **作者**：吴琦  

---

## 📖 项目简介
随着城市养宠家庭激增，“领养代替购买”与“科学养宠社群互动”成为养宠人群的核心诉求。  
本项目是一套集**流浪动物救助领养**、**宠物生活与健康档案管理**、**宠物周边与饲料商城**及**宠友互动社区**于一体的综合数字化平台。系统通过微信小程序提供低门槛的移动端领养与社群互动，配套 Spring Boot 后台支撑复杂的审核审批与订单核销闭环。

---

## 🛠️ 技术栈与全栈选型

### 1. 后端技术 (Backend)
* **核心框架**：Spring Boot 2.x
* **持久层**：MyBatis / MyBatis-Plus
* **数据库**：MySQL 8.0 (utf8mb4)
* **连接池与工具**：Alibaba Druid / HikariCP, FastJSON, JWT
* **服务运行端口**：`8080` (上下文: `/springboot2zemx`)

### 2. 前端小程序 (mp-weixin)
* **技术规范**：微信原生小程序开发体系 (WXML + WXSS + JavaScript)
* **交互能力**：瀑布流图片展示、领养申请表单、微信支付/模拟钱包结算、宠物资讯专区

## 🌟 核心业务板块与多端矩阵

### 1. 🐕 宠物领养与救助体系
* **遗弃与流浪宠物救助 (`yiqichongwuxinxi`)**：发布流浪动物发现地、健康状况、驱虫疫苗记录与照片。
* **领养申请与资格审核 (`lingyangxinxi`)**：领养人居住环境与收入资质填报、线上下单领养、救助站管理员后台审核。
* **宠物分类检索 (`chongwuleibie`)**：按犬类、猫咪、异宠等多维度筛选匹配。

### 2. 🦴 饲料与宠物周边商城
* **用品商城 (`siliaoshoumai`)**：宠物主粮、罐头冻干、玩具牵引绳等商品浏览。
* **购物车与结算流程 (`shop-cart`, `shop-order`)**：支持多件合并下单、收货地址管理、订单全生命周期追踪。

### 3. 💬 宠友互动社区圈子
* **宠物故事与动态 (`discussyiqichongwuxinxi`)**：晒宠发帖、日常萌照分享、点赞与评论交流。
* **科学养宠资讯 (`news`)**：疫苗接种科普、常见宠物疾病预防指南宣教。
* **个人中心 (`center`)**：我的领养申请进度、我的收藏、余额与充值管理。

## 🚀 本地快速启动指南

### 1. 数据库初始化
1. 启动本地 MySQL 服务；
2. 创建数据库 `springboot2zemx`；
3. 执行导入 [`sql/springboot2zemx.sql`](sql/springboot2zemx.sql)；
4. 如有需要，可在 `src/backend/src/main/resources/application.yml` 中调整数据库账号与密码（默认 `root` / `123456`）。

### 2. 启动 Spring Boot 后端
```bash
cd src/backend
mvn clean spring-boot:run
# 或在 IDEA 中直接启动 SpringbootSchemaApplication
# 后端服务访问地址: http://localhost:8080/springboot2zemx
```

### 3. 运行微信小程序端
1. 打开 **微信开发者工具**；
2. 选择「导入项目」，目录选择 `src/mp-weixin`；
3. 填入测试 AppID（或选择测试号）；
4. 进入微信模拟器即可完整体验宠物展示、领养申请与商城全流程。

## 💡 架构设计与心得
1. **多业态复合业务建模**：成功融合了“公益救助领养”与“宠物商业商城”两种不同形态的业务流，设计了健壮的订单与领养资质状态机；
2. **微信生态原生体验**：采用原生微信小程序组件开发，启动速度快、加载流畅，极大降低了用户参与领养与交流的门槛。
