# 🍵 茶文化主题 APP 与管理中台 (Tea Culture Platform)

> **研发与归档时间**：2024 年 06 月  
> **所属阶段**：02-实战进阶与商业小程序交付  
> **架构类型**：前后端分离 (Spring Boot 2.7 + Vue 3 + Uni-app 移动端多端)  
> **作者**：吴琦  

---

## 📖 项目简介
本项目是一套致力于传承中国传统茶文化、融合**茶文化知识科普**、**茶品在线商城**与**茶友互动社区**的数字化全栈平台。  
系统由三部分协同组成：**后端 RESTful 服务**、**Vue 3 PC 运营管理中台**以及**Uni-app 移动端跨端 APP/小程序**，实现了从茶文化内容宣发、茶艺商品交易到茶友社区圈子互动的全流程闭环。

---

## 🛠️ 技术选型与全栈架构

### 1. 后端服务 (Backend)
* **核心框架**：Spring Boot 2.7.18 (Java 17)
* **持久层**：MyBatis-Plus 3.5.x
* **数据库**：MySQL 8.0 (字符集 utf8mb4)
* **连接池**：HikariCP
* **接口服务端口**：`8080`

### 2. PC 运营管理中台 (Admin UI)
* **框架**：Vue 3 + Vite
* **UI 体系**：Element Plus
* **核心功能**：茶文化科普文章发布、商品品类维护、订单物流管理、茶友动态审核

### 3. 移动端 APP / 小程序 (App Uni-app)
* **框架**：Uni-app (Vue 3 规范) + Vite
* **多端编译**：支持发布为 Android/iOS APP、微信小程序以及移动端 H5
* **核心特性**：精致国风视觉排版、下拉刷新、茶友圈瀑布流、购物车结算

---

## 🌟 核心业务板块与多端矩阵

### 1. 移动端核心体验
* **茶文化大厅 (`pages/index`)**：六大茶类（绿茶、红茶、青茶/乌龙、黑茶、白茶、黄茶）深度图文科普、茶道历史与经典茶器鉴赏。
* **茶品商城 (`pages/mall`)**：核心产区名茶直采、精致茶具、加入购物车与在线模拟结算。
* **茶友社区 (`pages/community`)**：茶友交流发帖、茶汤品鉴心得分享、点赞评论互动。
* **个人中心 (`pages/user`)**：我的订单状态追踪、我的收藏夹、收货地址与个人资料管理。

### 2. PC 管理端运营管控
* **知识库管理**：茶文化图文百科、视频与冲泡技巧编排发布。
* **商品与库存**：商品上架下架、规格参数维护、库存阈值告警。
* **订单核销追踪**：全平台订单状态流转、发货与物流单号更新。
* **社区内容审核**：茶友动态合规巡检与违规评论拦截。

## 🚀 快速启动指南

### 1. 数据库准备
1. 启动本地 MySQL 服务；
2. 创建数据库 `tea_culture`（字符集 `utf8mb4`）；
3. 依次导入 [`sql/schema.sql`](sql/schema.sql) 与 [`sql/seed.sql`](sql/seed.sql)。

### 2. 启动后端 API 服务
```bash
cd src/backend
mvn clean spring-boot:run
# 或在 IDEA 中运行主类
# 服务地址: http://localhost:8080
```

### 3. 启动 PC 管理端
```bash
cd src/admin-ui
npm install
npm run dev
# 浏览器访问本地前端端口
```

### 4. 启动移动端 APP / 小程序
```bash
cd src/app-uniapp
npm install
npm run dev:h5            # 本地 H5 调试
# 或 npm run dev:mp-weixin # 微信小程序编译
```

## 💡 架构设计与沉淀
1. **内容 + 电商 + 社区复合架构**：将静态的茶文化科普、动态的社群交互与电商购物流程解耦，构建高黏性的垂直文化生态；
