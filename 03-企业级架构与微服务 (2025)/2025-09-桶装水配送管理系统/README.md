# 💧 桶装水配送管理系统 (Water Delivery Management System)

> **研发与归档时间**：2025 年 09 月  
> **所属阶段**：03-企业级架构与微服务实战  
> **架构类型**：前后端分离 (Spring Boot 3.x + Vue 3 + PC管理后台 + 移动端H5)  
> **作者**：吴琦  

---

## 📖 项目简介
本系统是针对水站/桶装水配送企业的业务场景打造的**企业级全流程数字化进销存与配送调度系统**。  
系统涵盖**后端微服务 API**、**PC 端运营调度管理中台**以及**移动端配送员 H5 作业端**，实现了从客户报修订水、智能派工调度、配送员抢单接单、电子签收到水站进销存盘点与财务结算的端到端数字化闭环。

---

## 🛠️ 技术栈与全栈架构

### 1. 后端技术 (Backend)
* **核心框架**：Spring Boot 3.1.5 (Java 17)
* **持久层**：MyBatis-Plus 3.5.5
* **数据库**：MySQL 8.0
* **鉴权安全**：JWT (jjwt 0.11.5) 无状态身份认证
* **接口规范**：Knife4j 4.3.0 (OpenAPI 3 / Swagger 3)
* **数据解析与工具**：FastJSON2, OkHttp3, Lombok

### 2. 前端管理中台 (Admin PC)
* **框架**：Vue 3 + Vite
* **UI 组件库**：Element Plus / 后台管理通用组件
* **路由与状态**：Vue Router 4 + Pinia
* **网络请求**：Axios 拦截器统一封装

### 3. 配送员移动端 (Courier H5)
* **框架**：Vue 3 + Vite
* **移动端交互**：移动端响应式布局、H5 定位与工单状态实时看板

---

## 🌟 核心业务矩阵与功能模块

### 1. PC 运营管理中台
* **综合数据大屏**：今日配送订单量、空桶回流率、派单效率统计、营收看板。
* **工单智能调度**：新订单智能推荐配送员、手动改派、异常工单挂起。
* **水站进销存 (WMS)**：各品牌桶装水入库、出库、批次盘点、安全库存阈值预警。
* **空桶押金管理**：客户押金台账、空桶回收入库、退押金核销记录。
* **客户档案管理**：企业客户、家庭住址、月结客户与协议价格管理。

### 2. 配送员 H5 移动作业端
* **工单中心**：待接单、配送中、今日已送达订单分类展示。
* **导航与联系**：一键拨打客户电话、地址位置查看。
* **签收与回桶**：现场拍照上传、输入本次回收空桶数量、完成订单交付。
* **个人业绩**：今日提成、本月送水总桶数、回桶达标率。

## 🚀 快速启动指南

### 1. 数据库准备
1. 启动本地 MySQL 服务；
2. 执行 [`sql/init_water_delivery.sql`](sql/init_water_delivery.sql) 完成建表与初始演示数据初始化。

### 2. 启动后端服务 (Backend)
```bash
cd src/backend
mvn clean spring-boot:run
# 或在 IDEA 中运行 WaterDeliveryApplication
# 服务端口：8088
```

### 3. 启动 PC 管理端 (Admin PC)
```bash
cd src/admin-pc
npm install
npm run dev
# 浏览器访问本地开发端口 (通常为 http://localhost:5173)
```

### 4. 启动配送员 H5 移动端 (Courier H5)
```bash
cd src/courier-h5
npm install
npm run dev
# 浏览器以移动端模拟模式访问
```

## 💡 架构亮点与技术沉淀
1. **全栈闭环**：不仅包含传统的管理后台，还设计并落地了配送员 H5 移动工作台，打通“线上订单 -> 仓库出货 -> 骑手配送 -> 空桶回流”全生命周期；
2. **现代技术栈演进**：采用最新的 **Spring Boot 3 + Java 17 + Vue 3 (Vite)** 组合，全面摆脱传统脚手架的历史包袱；
3. **空桶资产管理模型**：针对水站独有的“水与空桶分离”特性，设计了专门的押金与周转循环表结构，有效解决实际业务中的丢桶、漏记痛点。
