## 📌 项目整理原则与准则

1. **真实记录**：每一个阶段的项目均保留最初的代码风格与演进记录，不粉饰历史，只展现成长。
2. **规范工程化**：每个项目均剔除编译缓存、临时日志，提供完整的环境说明与启动文档。
3. **安全合规**：所有收录项目均完成敏感信息脱敏（包括个人私钥、商业账号密码、真实生产配置等）。
